# 问题反馈

这里用来收集使用中遇到的问题和建议。请到 [Issues](../../issues) 页面点「New issue」，选一个模板填写。

## 提交前请注意

- 这是**公开仓库**，任何人都能看到你写的内容。请不要贴手机号、邮箱、验证码、密钥、账号密码、学员姓名等个人信息，截图里也请打码。
- 先搜一下有没有人提过相同的问题，有的话在原帖里补充或点 👍。
- 一个 issue 只写一件事，方便跟进。

## 写清楚这几点，问题能更快解决

1. 在哪个页面、做了什么操作；
2. 期望看到什么，实际看到什么；
3. 出现的时间（大概到分钟）和任务编号（如果有）；
4. 用的设备和浏览器（电脑 / 手机，Chrome / Safari / 微信内置浏览器等）；
5. 截图或录屏（请先打码）。

涉及积分扣费、账号或隐私的问题，请联系机构客服处理，不要在这里公开填写账户信息。
